一技能阶段(根据状态划分)
技能范围


计量单位: 闪现 400码




    

  1. 内圈: 500码
    

    2. 

  2. 外圈: 900码 (算上内圈)
    

     
    

    3. 



阶段1
如果在唯一过程中检测到身后 50码 至身前 210码 范围内存在目标


    

  1. 实际位移距离: 460码
    2. 

  2. 位移效率: 836码/秒
    3. 



阶段2
停止位移进入 阶段2


    

  1. 姬小满向目标方向进行拉拽
    2. 



阶段3
对以目标为中心的矩形范围内所有目标在造成伤害后略微击飞 再瞬间拉拽至身前再回弹到距离姬小满 120码 的范围


    

  1. 控制时长: 0.5秒
    2. 

  2. 矩形范围以外扇形范围内则会根据类型不同施加不同的效果
      

    • 英雄单位: 只受到伤害附加 1秒30%减速
      • 

    • 非英雄单位 : 被拉拽
      • 

    

    3. 



bug


各类判定
身后判定
    

  1. 当一技能释放时检测到身后 50码至身前 210码 范围内存在可锁定单位一技能跳过 阶段1 直接从 阶段2 开始释放
    

    

    用人话来说姬小满不跑步直接开抓
    

    

    2. 



视野判定
    

  1. 被一技能命中的目标会暴露视野 2.8秒
    

    可惜的是 无法破隐
    

    
 出伤就爆视野 不必拉拽成功
    2. 



交互判定
    

  1. 位移终端可跨墙拉人
    

    

    无法带人过墙
 
    

    

    2. 

  2. 拉拽无法对位置重合的目标造成位移效果
    

    3. 



联动
配合闪现
    

  1. 阶段1 闪现改变位移方向
    

    

    常用于闪现 开 / 过人
    

    

    2. 

  2. 阶段2 闪现改变拉拽攻击范围
    

    

    闪现藏前摇敌人无法反应
    

    

    3. 

  3. 阶段3 闪现改变拉拽目标最终落点
    

    

    限于开始回弹前
    

    

    4. 



韧性
    

  1. 韧性不改变最终落点但会减少控制时长
    

    

    拉回速度更快如鲁班大师 
    

    

    2. 

  2. 拉回距离上限 500码
    

    

    回来吧我的超绝吸力 (态君哭泣)
    

    

    3. 



缓存
    

  1. 技能全程可缓存指令
    

     一技能途中点了技能/普攻会在技能结束后自动衔接
    

    

    利用好缓存机制制可以与闪现产生奇妙配合
    

    

    2. 

  2. 缓存11闪
    

    

    没有1闪后手动补1的间隙连招更迅捷
    

    

    3. 

  3. 缓存12闪
    

    

    没有1闪后手动补2的间隙连招更迅捷
    

    

    4. 



与他人技能的交互
    

  1. 拉拽可以改变部分英雄的位移方向
    

    2. 

  2. 同样一技能位移也会被部分特殊控制改变方向
    

    

    如弈星2老夫子1钟道3特殊情况下司空震2
    

    

    3. 



索敌设置
    

  1. 一技能会受设置优先攻击目标改动影响
    

     除了最近单位
    

    2. 

  2. 开启最近单位时一技敌默认为百分比最低
    

    3. 

  3. 当目标存在于指示器范围 500码 内优先索敌精准锁定目标回8
    

    

    可通过滑动普攻精确锁定或头像锁定达成
    

    

    4. 

  4. 技能不受设置位移默认方向改动影响
    

    

    默认为敌方目标回城闪现控制
    

    

    5. 



细节
控距
    

  1. 位移极限距离在转阶段前停止位移时会原地踏步（抓人前摇更大所以远距离1容易被位移躲开
    2. 

  2. 中距离1停止位移直接秒抓《无原地踏步僵直）
    3. 



判定


顺带一提因为一技能出伤比控快 所以可以斩杀残血瑶)




一技能控制生效前摇 4帧 (60帧条件下)


态君小课堂 如何呢
控制生效前摇当目标受到控制时不会立即发挥效果(如禁用技能按键、打断释法），而是在短暂延迟后




是的 这就是很多霸体能在脑袋上挂着控制效果时却能放出来清除控制的原因




bug
    

  1. 元歌傀儡会受到双倍拉拽伤害(同时傀儡被判定非英雄单位）
    2. 

  2. 在使用大乔大招传送后一秒内位移方向会强制锁定为原位置指向现位置的方向 （表现形式为太空步）
    3. 

  3. 暂停么? 在这里你并不需要这么做
    4. 



理论么 有意思
    

  1. 一技能位移为一般位移不可穿墙(具有强制施法效果）拉拽过程不会被非一级控制打断
    

    2. 

  2. 当位移过程中遭受三级控制（如眩晕）位移不会被打断当在位移终点判定到目标则会拉拽
    

     但如果没到位移终点就判定到目标则不会拉拽
    

    3. 

  3. 当位移过程中遭受二级控制（嘲讽除外）打断位移效果不影响拉拽判定
    

    4.
